All workshop participants are expected to follow this Code of Conduct. ### Operating-system instructions #### Windows Git is installed as part of Git for Windows, which also provides Git Bash. If you completed the Windows setup for one of the Unix Shell workshops, Git is already installed. Open **Git Bash** and continue to [Confirm that Git works](#confirm-that-git-works). If you did not complete the Unix Shell setup, follow the [Windows installation instructions from the Unix Shell workshop]({{ '/events/unix-shell-offering-2/' | relative_url }}) before continuing. Those instructions install Git Bash and configure the editor and default branch settings used during this workshop. If your Tennessee Tech-managed computer prevents installation, contact the ITS Help Desk, visit our open office hours, or bring the computer to the workshop and arrive early. #### macOS 1. Open **Terminal** from Applications → Utilities, or search for it with Spotlight. 2. Type the following command and press **Return**: ```bash git --version ``` 3. If Git is installed, you will see its version number. 4. If macOS prompts you to install the command-line developer tools, select **Install** and follow the instructions. **Do not select “Get Xcode.”** The full Xcode application is large and is not required for this workshop. After installation, you will not see a new Git application in your Applications folder. Git and the command-line developer tools are used through Terminal. #### Linux Git may already be installed. Open a terminal and enter: ```bash git --version ``` If Git is not installed, use your distribution's package manager. ##### For Debian or Ubuntu: First, update the package information: ```bash sudo apt update ``` Then install Git: ```bash sudo apt install git ``` ##### For Fedora: ```bash sudo dnf install git ``` ### Create a GitHub account Parts of the workshop use [GitHub](https://github.com/) to demonstrate sharing and collaborating on repositories. Basic GitHub accounts are free. Before creating your account, consider what personal information you want associated with the account. GitHub provides instructions for [keeping your email address private](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address). ##### If you do not already have an account, create one before the workshop: [Create a GitHub account](https://github.com/signup?ref_cta=Sign+up&ref_loc=header+logged+out&ref_page=%2F&source=header-home) After creating the account: 1. Verify your email address. 2. Complete GitHub's two-factor authentication setup if prompted. 3. Confirm that you can sign in successfully. ### Confirm that Git works Open Git Bash on Windows or Terminal on macOS or Linux and enter: ```bash git --version ``` You should see output similar to: ```text git version 2.51.0 ``` Your exact version number may be different.
