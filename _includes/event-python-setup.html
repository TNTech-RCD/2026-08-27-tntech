### Create the workshop environment

A Python environment keeps the version of Python and the packages for this workshop together. The file below tells Miniforge which packages to install, including NumPy and Matplotlib. You create this environment only once; you activate it each time you return to the workshop.

  1. Right-click the workshop environment file and select Save link as. Save it in Downloads with the name carpentries_environment.yml. Check that your browser has not added .txt to the filename.
  2. Open Git Bash. This is where you will type the following commands.
  3. Navigate to the folder where you saved the file. If it is in your usual Downloads folder, enter: 
    cd ~/Downloads
    If your Downloads folder is redirected through OneDrive, navigate to its actual location instead, as you did in the earlier workshops.
  4. Check that Git Bash can see the file: 
    ls carpentries_environment.yml
    You should see the filename printed. If you see “No such file or directory,” check the folder and filename before continuing.
  5. Create the workshop environment: 
    conda env create -f carpentries_environment.yml
    Miniforge will read the file and install Python, NumPy, Matplotlib, and the other packages listed in it. This may take several minutes.
  6. When the command finishes and you can type again, activate your new environment by entering: 
    conda activate carpentries
    You should see (carpentries) near the beginning of the Git Bash prompt.

Download the [lesson data ZIP file](https://swcarpentry.github.io/python-novice-inflammation/data/python-novice-inflammation-data.zip) and the [lesson code ZIP file](https://swcarpentry.github.io/python-novice-inflammation/files/code/python-novice-inflammation-code.zip). 2. If your Desktop is redirected through OneDrive, use the Desktop location you have used in the previous workshops. ### Check your setup Open **Git Bash** on Windows or **Terminal** on macOS or Linux. Activate the workshop environment: ```bash conda activate carpentries ``` You should see `(carpentries)` near the beginning of the prompt. Now check that Python can load the packages used in the lesson: ```bash python -c "import numpy, matplotlib.pyplot; print('Python setup is ready')" ``` If you see `Python setup is ready` without an error, the software is ready. Finally, confirm that your Desktop `swc-python` folder contains `data` and `code` directly inside it, and that `data` contains `inflammation-01.csv`.
